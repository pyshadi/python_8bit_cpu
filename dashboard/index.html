Getting started

Brassboard runs the real Python emulator from this repository inside your browser. Nothing is installed; the first visit downloads Python (about 10 MB), and later visits use the cached copy.

  1. Pick a program from Program, or press New above Source to start your own. Your programs are saved in this browser as you type.
  2. Assemble happens automatically as you type. Errors appear under Source and mark their line; ⌘↵ or Ctrl↵ assembles immediately.
  3. Set breakpoints by clicking a line number, or with F9 on the line with the cursor. Only lines with an instruction can hold one.
  4. Step one instruction with F10, or run with F5 at the Clock rate. The machine stops at a breakpoint, hlt or an error.
  5. Read the result: registers written by the last instruction are outlined, and every instruction appears in Trace.

Programs

Your programs are saved automatically as you type. They are kept in this browser on this computer only, so use Download to keep a copy elsewhere or move a program to another machine.

Controls

On a Mac, function keys may need the fn key.

Lamps and colors

Color on the console always describes the machine.

Brass: live

The current line, set flags and bits, return addresses on the stack, the program counter in ROM, jumps in Trace, and the Run and Break lamps.

Patina: written

Registers and RAM written by the last instruction, values on the stack, and writes in Trace.

Signal: stopped

Breakpoints, the Halt lamp, and assembler or runtime errors.

LampLit when
RunThe machine is running at the Clock rate.
BreakStopped at a breakpoint, after a step, or paused.
HaltThe program reached hlt or stopped with a runtime error. Reset to run it again.
Z · C · V · SZero, carry, overflow and sign flags in register F, set by the last arithmetic, logic or compare instruction.

Panels

SourceColumns from left: breakpoint, line number, address of the instruction on that line, code. The highlighted line is the next instruction to run.
RegistersEach 8-bit register shows hex, decimal and eight bit lamps (most significant on the left). PC and SP are 16-bit. F shows the four flags.
Data pathWhat the next instruction will do before it runs: the parts of the machine it uses (outlined in brass), the values it reads, and on the lit wires the values it will write, the flags it will set, or where it will jump (“not taken” when a jump won't happen). If the instruction would fail, the panel heading says why.
Memory: mapOne square per RAM byte, starting at 0000 in the top left: 64 bytes per row for 1 KB and 4 KB, 256 per row for 64 KB. Dark squares are zero, grey squares hold data, patina squares are the stack in use, brass squares are return addresses pushed by call, and bright squares were written by the last instruction. Click a square to show that address.
Memory: dumpEight rows of RAM around SP (outlined in brass). Type an address (0x0100, 256) or a label and press Enter to show that area instead; Follow SP returns to the stack. Click a byte to select it.
Memory: stackThe stack from the top (SP) down: pushed values in decimal, and return addresses as ret 000E (label).
Memory: ROMThe assembled program bytes. The next instruction is filled in brass; bytes where a breakpoint stops are outlined in red.
TraceThe Trace tab next to Data path lists recent instructions: cycle, address, bytes, instruction and its effect. All shows the last 200 instructions with the next one highlighted; Memory writes and Jumps each keep the last 200 of their kind, even from long runs.

Assembly reference

  • Operands are separated by commas: mvi, A, 10. A label is a name followed by a colon, on its own line or before an instruction: loop: dec, C.
  • ; starts a comment. Mnemonics and register names are not case-sensitive.
  • Numbers can be decimal, 0x10, 0b101 or 0o17. Immediate values (imm) are 0–255; addresses (mem) and labels are 0–FFFF.
  • Registers: A–L, X, Y, SP, PC. F holds the flags and is overwritten by arithmetic.
  • Instructions with two registers (add, B, C) put the result in A; forms with imm or mem write back to their register. RAM is 1 KB unless you choose 4 KB or 64 KB, and the stack starts at its top.
